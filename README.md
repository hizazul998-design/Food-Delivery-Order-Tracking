
# Food Delivery Order Tracking System

## Project Description
This project implements a food delivery order tracking system using the Observer Design Pattern in Python.

## Features
- Track order status.
- Add observers dynamically.
- Remove observers dynamically.
- Notify all registered observers.
- Send SMS-style notifications to customers.
- Display notifications on the kitchen screen.
- Stop kitchen notifications after delivery.

## Technologies Used
- Python 3
- Observer Design Pattern
- Unit Testing

## Project Files
- order.py
- observers.py
- main.py
- test_order.py
- UML_Diagram.puml

## How to Run

Run the main program:

python main.py

## How to Test

Run the test file:

python -m unittest -v
